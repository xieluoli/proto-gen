# PRD 文档结构规范

> **适用范围**：设备无关。把一个功能模块的原型或构思，整理成结构统一的 PRD **文档**（`.md`）。
>
> 与 [`prd-rules.md`](prd-rules.md) 的分工：**本文管「整篇文档怎么组织」**（章节骨架、框架图、配置表、命名约定）；**每一条 bullet 怎么写**（元素描述模板、重复内容引用、改动型只写增量、产品语言禁代码语言）一律看 `prd-rules.md`，本文不复述。
>
> 只要原型旁注面板、不要独立文档的项目，可以跳过本文，只用 `prd-rules.md`。

核心原则：**一个可感知元素一条、单一职责、按视觉布局顺序、数据来源说人话不写实现**。

## 各章节要点

### 功能概览

- 第一行：一句话概述模块定位（非列表项）
- 正文按**视觉 section 分组**，每组用三级标题 `### {编号}：{页面短名}`
- 每组下用无序列表，**不使用 `功能N：` 编号**
- 列表项按页面**从上到下视觉布局顺序**排列（顶部标题/工具条 → 主区 → 操作按钮 → 弹窗/抽屉）

每条 bullet 的写法——加粗元素名前缀、按元素类型套描述模板、数据来源说人话、改动型只写增量、多 section 重复内容如何引用——全部见 [`prd-rules.md`](prd-rules.md)。

### 框架

- 用 ASCII 树形图（`├──` `└──` `│`）
- 展示该模块的子页面及其编号
- 同类页面可合并，标注「同模板不同状态」
- 可选：往下延伸一层展示兄弟模块

### 配置表

- 字段全部合并到**一张主表**，首列 `分组` 标识类别（基本信息 / 展示与分类 / 安装配置 / 依赖项 / 截图…）
- 列：`分组 | 字段 | 类型 | 说明`，**不设「示例」列**（示例统一放 YAML）
- 字段名用反引号包裹
- 数组/嵌套对象字段在主表标记类型（如 `object[]`），下方另起小表展开
- 附完整 YAML 示例：**列表/数组类字段至少给 2 条**，体现「多项」结构
- 如有状态判定逻辑，最后补判定表

## 格式约定

| 约定 | 说明 |
|------|------|
| 语言 | 中文，技术术语保留英文 |
| 标题 | `##` 章节，`###` 子节 |
| 分隔 | 章节间不留 `---` 分隔线 |
| 强调 | 单句核心原则用 `> ⚠️` blockquote |
| 字段名 | 反引号包裹，如 `` `name` `` |
| 示例值 | 双引号包裹字符串 |
| 代码块 | 标注语言类型，如 ` ```yaml ` |
| 表格 | 表头加粗，列对齐用空格保持一致 |
| 功能列表 | 按 `### 编号` 分组的无序列表，不使用 `功能N：` 编号；每条以 `**元素名**：` 加粗标题前缀起头 |
| 数组示例 | YAML 示例中数组字段至少给 2 条 |

## 命名约定

| 事项 | 格式 | 示例 |
|------|------|------|
| 原型图编号 | `{tab名}-{序号}` | `用户中心-01`、`用户中心-02` |
| 配置字段 | snake_case | `description_short`、`install_command` |
| 枚举值 | 双引号字符串 | `"cli"`、`"recommended"` |
| 锚点 ID | kebab-case | `section-home`、`section-home-loading` |

## 与 HTML 原型耦合

> 仅当项目有可点击的 HTML 原型时适用；纯文档项目跳过本节。

- **原型图引用**：用 blockquote 放标题下方，`>` 开头；链接指向 HTML 锚点，格式 `[编号](相对路径#锚点)`；多链接用 `·` 分隔，可换行。
- **md 与 HTML 面板同步**：功能概览同时存在于 `.md` 与 HTML 旁注面板（prd-panel `<li>`）时，两处修改必须同步。
